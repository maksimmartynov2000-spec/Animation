# Претенденты — правила проекта для Claude

## Что это
Карточная игра «Претенденты» — прототип настольной игры, браузерная версия. Весь сайт — один файл `index.html` в корне репозитория, его отдаёт GitHub Pages. Исходники — в `src/`. Владелец проекта играет в основном вдвоём с женой: каждый на своём устройстве, по сети или против ботов, запуск с иконки на экране «Домой».

## Сборка
- `npm install` (esbuild для сжатия; Playwright для тестов).
- `npm run build` → `src/dist/*.html` и **`index.html` в корне** (корень сайта отмечен файлом `.pretendenty-site`).
- После любой правки исходников пересобрать и закоммитить `index.html` вместе с исходниками — иначе на сайте ничего не изменится.
- `index.html` должен оставаться меньше 2 МБ (сейчас ~1,6 МБ).

## Выпуск версии
1. Поднять `VERSION` в `src/ui.js` (например 10.7 → 10.8), в комментарии — что нового.
2. Добавить раздел в `src/REDESIGN.md` (что и зачем поменяли).
3. Собрать и проверить (ниже).
4. Ветка и PR с понятным описанием на русском. **Не мержить** — мержит владелец.

После мержа GitHub Pages обновит сайт за 1–2 минуты. Проверить, что сайт обновился (доступ к github.io открыт в среде «Журнал»):
`curl -s -r 0-8191 "https://maksimmartynov2000-spec.github.io/Animation/?chk=$(date +%s)" | grep -o 'pretendenty-build" content="[^"]*'` — метка должна совпасть с `index.html` из `main`. В `index.html` есть метка сборки `<meta name="pretendenty-build">`: игра на устройствах сама находит новую сборку и обновляется — на главном экране сразу, на итогах и в сетевой комнате кнопкой, во время партии молчит.

## Проверка
- `npm run test:engine` — движок: каждое свойство карт (должно быть «0 не прошли»).
- Браузерные тесты (Playwright): при необходимости `npx playwright install chromium`, затем `python3 tests/make-page.py` и `node tests/<имя>.js`. Основные: `info.js`, `kb.js`, `buy.js i15|mini|mac`, `buy2.js`, `handplay.js`, `faith.js i15|mini|mac`, `tab.js i15|mini`, `tut.js i15|mini`, `fly.js`, `head.js`, `headbig.js`, `cards.js`, `upd.js`, `prefs.js`, `pair.js`, `net2.js`, `table3.js`, `standalone.js`. Прогон целой партии: `node tests/monkey.js games=1 turns=100` (размер окна — `w= h=`). Скриншоты и рабочие файлы — в `.work/`.
- Главные устройства: iPhone 15 (393×852) и iPad mini (744×1133); ещё iPhone 12 Pro Max, iPad 11", MacBook (1512×900), любая ориентация. Настоящий Safari в песочнице не проверить — для этого в игре есть «Меню → Проверка устройства» (отчёт одной кнопкой).

## Как работать с владельцем
- По-русски, на «вы», неформально и коротко, без воды и лишних оговорок. В конце — 2–3 пункта, что можно раскрыть подробнее.
- Перед большой работой — уточняющие вопросы одним блоком (у каждого 2–4 варианта и свой ответ).
- Правила и баланс игры не менять без прямой просьбы.
- Не выдумывать: не знаешь — проверь или так и скажи. Ошибается — сказать прямо, с доводами.

## Устройство кода
- `data.js` — карты, Дома, веры, правила; `engine.js` — движок и боты; `ui.js` — весь интерфейс; `pcards.js` — вид «печатных» карт; `cardfx.js` — значки эффектов; `net.js` — игра по сети (публичные MQTT-брокеры); `style.css`, `board.css`, `menu.css` — стили (тема «сукно, дерево, золото»); `build.py` — сборка.
- Рисунки карт — SVG в `src/dist/art` и `src/dist/icons`; в `index.html` они встраиваются при сборке.
- Решения по интерфейсу и история версий — `src/REDESIGN.md`.
- Не использовать имена классов из старого `style.css`: `.opp, .opps, .me, .res, .feed, .dice, .die, .hand, .cnt, .chip, .fx, .fxs, .dot, .top, .card`. Правилам для `<button>` нужна специфичность не ниже `.board X`.
