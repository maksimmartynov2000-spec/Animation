# Претенденты

Карточная игра про борьбу Домов за трон — прототип настольной игры в браузере.

- **Играть:** `index.html` в корне — это вся игра одним файлом, его отдаёт GitHub Pages. Можно добавить на экран «Домой» на iPhone/iPad.
- **Исходники:** папка `src/` (данные карт, движок, интерфейс, стили, рисунки).
- **Собрать:** `npm install`, затем `npm run build` — обновятся `src/dist/` и `index.html` в корне.
- **Проверить:** `npm run test:engine`; браузерные тесты — в `tests/` (см. `CLAUDE.md`).

Игра сама проверяет, не вышла ли новая версия на сайте, и обновляется вне партии.
